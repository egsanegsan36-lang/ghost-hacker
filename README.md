🔗 **ربات:** https://t.me/ghost_hacker_ehsan_bot

## قابلیت‌ها
- 🌐 **بررسی IP:** اطلاعات عمومی و موقعیت تقریبی
- 🛡 **بررسی امنیت سایت:** هدرهای امنیتی، HTTPS و ریدایرکت (فقط برای سایت خودت یا با مجوز)
- 🔗 **تحلیل لینک مشکوک:** تشخیص الگوهای فیشینگ بدون باز کردن لینک
- 🔐 **بررسی قدرت رمز عبور:** کاملاً داخل مرورگر؛ رمز هیچ‌جا ارسال نمی‌شود
- 🧪 **آزمایشگاه رمزگشایی:** چالش‌های آموزشی با راهنما و امتیاز
- 💻 **ترمینال نمایشی:** نمایش شبیه‌سازی‌شده (بدون عملیات واقعی)
- 📚 **آموزش ترفندهای سایبری:** نکات کوتاه و کاربردی
- 👤 **حساب کاربری، امتیاز و سطح**

## حریم خصوصی
- ثبت‌نام با شماره‌ی تلفن (با دکمه‌ی رسمی تلگرام) انجام می‌شود و شماره فقط برای مدیریت حساب نگه‌داری می‌شود.
- کاربر هر زمان می‌تواند از «تنظیمات ← حذف همه‌ی داده‌ها» اطلاعاتش را پاک کند.
- رمز عبور، متن لینک‌ها و پیام‌های کاربران ذخیره نمی‌شوند.
